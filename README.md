# bids.sunspotparadise.com

Portada pública de la licitación Marina 5 (Sunspot Paradise Inc.), publicada con GitHub Pages.

- `index.html`: portada con los botones "Acceder al portal" y "Guía del portal de licitación".
- `guia/index.html`: la guía pública. Se genera desde `src/client/tutorial.html` del repositorio del portal (`licitacion`); para cambiarla se cambia allí y se vuelve a generar.
- `assets/`: logos.
- `CNAME`: el dominio propio.

No contiene nada del portal ni datos: solo estas páginas estáticas.
